Both tools “fetch keywords” by first analyzing the top-ranking pages for a target query, then extracting the words, phrases, and entities that repeatedly appear across those pages. Surfer appears to emphasize SERP scanning, grouping terms by intent, and surfacing sub-keywords, while NeuronWriter emphasizes NLP terms, semantic clusters, and entities. ## How Surfer does it

Surfer’s documentation says it scans the top-performing Google pages for your keyword, then identifies what terms they rank for and how those terms are grouped by intent. Its keyword research flow also produces related keywords, similar keywords, same terms, questions, and a SERP similarity measure so you can see which terms are shared across ranking pages. In the Content Editor, Surfer can pull in competitor pages or a published URL, then generate a brief based on the chosen keyword cluster and the top ranking URLs. [surferseo](https://surferseo.com/blog/keyword-research-guide/)

In practice, Surfer is likely using a mix of:
- **SERP retrieval** for the target query.
- **Term extraction** from the top pages.
- **Intent clustering** to group terms into topic buckets.
- **Frequency and similarity ranking** to decide which terms matter most. [robbierichards](https://www.robbierichards.com/seo/surfer-seo-review/)

## How NeuronWriter does it

NeuronWriter says its NLP Terms feature analyzes top-ranking results and extracts semantically related words, synonyms, variants, and related concepts rather than just literal keyword matches. It also explicitly groups suggestions into basic, supplementary, and contextual terms, and its keyword analysis feature highlights semantic topic suggestions and entities like people, places, and brands. That means it is not just counting repeated phrases; it is trying to infer which concepts are necessary to fully cover the topic. [neuronwriter](https://neuronwriter.com/optimization-how-neuronwriter-and-the-nlp-terms-function-can-improve-your-seo/)

In practice, NeuronWriter is likely using:
- **SERP collection** for the target keyword.
- **NLP-based phrase extraction** from ranking pages.
- **Entity detection** to identify important concepts.
- **Semantic grouping** to organize terms by importance and context. [undetectable](https://undetectable.ai/blog/neuronwriter-review/)

## Why this helps SEO

This is what makes both tools useful: they are not guessing keywords from a dictionary; they are inferring the **actual language pattern** of pages that already rank. That gives you a better map of topical coverage, missing subtopics, and the wording search engines seem to associate with successful pages. The real advantage is that the keyword list becomes a proxy for search intent and topical completeness, not just a bag of phrases. [neuronwriter](https://neuronwriter.com/features/keyword-analysis/)

Here is the full keyword extraction and content scoring algorithm, inspired by how both Surfer SEO and NeuronWriter work under the hood.

## What the code does

The pipeline has **4 stages**, each mapping directly to how Surfer and NeuronWriter operate:

### Stage 1 — Surfer-style TF·IDF Term Extraction
Runs `TfidfVectorizer` across all your reference articles. Terms are ranked by a weighted score: **60% TF·IDF weight** (how important a term is within the corpus) + **40% document frequency** (how many reference pages it appears on). This mimics Surfer's approach of surfacing terms that are consistently present across top-ranking SERP pages. [docs.surferseo](https://docs.surferseo.com/en/articles/11891594-keyword-research)

### Stage 2 — NeuronWriter-style NLP Entity Extraction
Uses `spaCy` NER to detect **entities** (brands, people, places, products) and **noun chunks** (semantic concept phrases like "search intent" or "title tag optimization"). Each term gets a **salience score = frequency × document spread ratio**, so entities mentioned across many reference pages rank higher than those mentioned once. [neuronwriter](https://neuronwriter.com/optimization-how-neuronwriter-and-the-nlp-terms-function-can-improve-your-seo/)

### Stage 3 — Term Priority Classification
Classifies all extracted terms into three tiers — exactly like NeuronWriter's taxonomy: [neuronwriter](https://neuronwriter.com/optimization-how-neuronwriter-and-the-nlp-terms-function-can-improve-your-seo/)
- **Must-have** — high TF·IDF score (≥ 65%) or appear in 70%+ of references
- **Supplementary** — medium relevance or widely spread entities
- **Contextual** — low-frequency enrichers that add topical depth

### Stage 4 — Blended Content Score (0–100)
Scores the draft using the formula from the previous discussion:

\[
\text{Score} = 100 \times (0.30S + 0.20E + 0.20I + 0.15O + 0.15Q) - P
\]

| Variable | What it measures | How it's calculated |
|---|---|---|
| **S** – Semantic coverage | Must-have + supplementary term hits | Weighted recall against classified terms |
| **E** – Entity coverage | Core entity presence | Entities with spread ≥ 0.4 found in draft |
| **I** – Intent coverage | Topical similarity to references | Cosine similarity via TF·IDF (sklearn) |
| **O** – On-page structure | Headings, word count alignment | H1/H2 presence + length ratio vs avg reference |
| **Q** – Quality | Lexical diversity + paragraph depth | Unique token ratio + avg words per paragraph |
| **P** – Penalties | Over-optimization and thin content | Deductions for stuffing, bloat, thin copy |

code = '''"""
SEO Content Scorer — Hybrid Surfer + NeuronWriter approach
Extracts keywords from reference articles and scores your draft.

Dependencies:
    pip install requests beautifulsoup4 nltk scikit-learn spacy
    python -m spacy download en_core_web_sm
"""

import re
import math
import string
from collections import Counter, defaultdict
from typing import List, Dict, Tuple

# ── Optional heavy imports (graceful fallback if not installed) ──────────────
try:
    import spacy
    nlp = spacy.load("en_core_web_sm")
    SPACY_AVAILABLE = True
except Exception:
    SPACY_AVAILABLE = False

try:
    from sklearn.feature_extraction.text import TfidfVectorizer
    from sklearn.metrics.pairwise import cosine_similarity
    SKLEARN_AVAILABLE = True
except Exception:
    SKLEARN_AVAILABLE = False

try:
    import nltk
    from nltk.corpus import stopwords
    from nltk.stem import WordNetLemmatizer
    nltk.download("stopwords", quiet=True)
    nltk.download("wordnet", quiet=True)
    STOP_WORDS = set(stopwords.words("english"))
    lemmatizer = WordNetLemmatizer()
    NLTK_AVAILABLE = True
except Exception:
    STOP_WORDS = set(["the","a","an","is","it","in","of","to","and","for","with","on","at","by","this","that","are","was","were","be","been","being","have","has","had","do","does","did","will","would","could","should","may","might","shall","can","need","dare","ought","used","as","if","or","but","not","from","into","through","during","before","after","above","below","between","each","few","more","most","other","some","such","than","too","very","just","because","while","although"])
    NLTK_AVAILABLE = False


# ════════════════════════════════════════════════════════════════════
# STEP 1 — TEXT UTILITIES
# ════════════════════════════════════════════════════════════════════

def clean_text(text: str) -> str:
    """Lowercase, remove HTML tags, collapse whitespace."""
    text = re.sub(r"<[^>]+>", " ", text)
    text = re.sub(r"\\s+", " ", text.lower())
    return text.strip()

def tokenize(text: str) -> List[str]:
    """Simple word tokenizer with punctuation removal."""
    text = clean_text(text)
    tokens = re.findall(r"\\b[a-z][a-z\\-]{1,}\\b", text)
    if NLTK_AVAILABLE:
        tokens = [lemmatizer.lemmatize(t) for t in tokens]
    return [t for t in tokens if t not in STOP_WORDS and len(t) > 2]

def extract_ngrams(tokens: List[str], n: int) -> List[str]:
    """Return n-grams as space-joined strings."""
    return [" ".join(tokens[i:i+n]) for i in range(len(tokens) - n + 1)]


# ════════════════════════════════════════════════════════════════════
# STEP 2 — SURFER-STYLE: TF·IDF TERM EXTRACTION
# Extracts terms by how important they are across the SERP corpus
# (frequent in ranking pages but not generic across all web text)
# ════════════════════════════════════════════════════════════════════

def surfer_style_tfidf_terms(
    reference_texts: List[str],
    top_n: int = 60,
    ngram_range: Tuple[int, int] = (1, 3),
) -> Dict[str, float]:
    """
    Mimics Surfer SEO's term extraction:
    - Runs TF·IDF across the reference (SERP) corpus
    - Returns terms scored by their TF·IDF weight
    - Higher = more specific to this topic cluster
    """
    if not SKLEARN_AVAILABLE:
        raise ImportError("pip install scikit-learn")

    cleaned = [clean_text(t) for t in reference_texts]
    vec = TfidfVectorizer(
        ngram_range=ngram_range,
        stop_words="english",
        max_features=500,
        sublinear_tf=True,
    )
    matrix = vec.fit_transform(cleaned)
    feature_names = vec.get_feature_names_out()

    # Mean TF·IDF across documents → terms that consistently appear
    mean_scores = matrix.mean(axis=0).A1
    term_scores = dict(zip(feature_names, mean_scores))

    # Also factor in document frequency (prefer terms in 3+ references)
    doc_freq = (matrix > 0).sum(axis=0).A1
    df_scores = dict(zip(feature_names, doc_freq / len(reference_texts)))

    # Final Surfer-style score: weighted combination
    combined = {}
    for term in feature_names:
        combined[term] = (0.6 * term_scores[term]) + (0.4 * df_scores[term])

    return dict(sorted(combined.items(), key=lambda x: -x[1])[:top_n])


def extract_headings(html_text: str) -> List[str]:
    """
    Surfer also extracts heading structure (H1–H3) to identify
    expected subtopics. Returns a list of heading strings.
    """
    pattern = re.compile(r"<h[1-3][^>]*>(.*?)</h[1-3]>", re.IGNORECASE | re.DOTALL)
    return [re.sub(r"<[^>]+>", "", h).strip() for h in pattern.findall(html_text)]


# ════════════════════════════════════════════════════════════════════
# STEP 3 — NEURONWRITER-STYLE: NLP ENTITY + SEMANTIC TERM EXTRACTION
# Extracts named entities and semantic term clusters
# ════════════════════════════════════════════════════════════════════

def neuronwriter_style_nlp_terms(
    reference_texts: List[str],
    top_n: int = 60,
) -> Dict[str, dict]:
    """
    Mimics NeuronWriter's NLP Terms extraction:
    - Uses spaCy NER to extract entities (people, places, brands, concepts)
    - Groups terms into: ENTITY, NOUN_CHUNK, KEYWORD
    - Scores by salience = frequency × document_spread
    """
    if not SPACY_AVAILABLE:
        raise ImportError("pip install spacy && python -m spacy download en_core_web_sm")

    entity_counter = Counter()
    entity_type_map = {}
    noun_chunk_counter = Counter()
    doc_entity_sets = []

    for text in reference_texts:
        doc = nlp(clean_text(text)[:100000])  # spaCy limit guard

        # Named entities (NeuronWriter entity layer)
        doc_ents = set()
        for ent in doc.ents:
            if ent.label_ in ("ORG","PERSON","GPE","PRODUCT","WORK_OF_ART","EVENT","NORP","FAC","LOC","LANGUAGE","LAW"):
                key = ent.text.lower().strip()
                entity_counter[key] += 1
                entity_type_map[key] = ent.label_
                doc_ents.add(key)
        doc_entity_sets.append(doc_ents)

        # Noun chunks (semantic concepts beyond single words)
        for chunk in doc.noun_chunks:
            phrase = chunk.text.lower().strip()
            phrase = re.sub(r"^(the|a|an)\\s+", "", phrase)
            if len(phrase.split()) >= 2 and len(phrase) < 60:
                noun_chunk_counter[phrase] += 1

    n_docs = len(reference_texts)

    # Salience score = tf × spread_ratio
    entity_scores = {}
    for ent, freq in entity_counter.items():
        spread = sum(1 for s in doc_entity_sets if ent in s) / n_docs
        entity_scores[ent] = {
            "score": round(freq * spread, 4),
            "type": "ENTITY",
            "entity_label": entity_type_map.get(ent, "MISC"),
            "frequency": freq,
            "doc_spread": round(spread, 2),
        }

    noun_scores = {}
    for phrase, freq in noun_chunk_counter.items():
        spread = freq / n_docs
        noun_scores[phrase] = {
            "score": round(freq * spread, 4),
            "type": "NOUN_CHUNK",
            "frequency": freq,
            "doc_spread": round(spread, 2),
        }

    # Merge and sort by score
    all_terms = {**entity_scores, **noun_scores}
    sorted_terms = dict(
        sorted(all_terms.items(), key=lambda x: -x[1]["score"])[:top_n]
    )
    return sorted_terms


# ════════════════════════════════════════════════════════════════════
# STEP 4 — TERM PRIORITY CLASSIFICATION
# Classify into must-have / supplementary / contextual (like NeuronWriter)
# ════════════════════════════════════════════════════════════════════

def classify_terms(
    tfidf_terms: Dict[str, float],
    nlp_terms: Dict[str, dict],
    n_references: int,
) -> Dict[str, List[str]]:
    """
    Classifies extracted terms into 3 tiers:
      - MUST_HAVE:     High TF·IDF + appears in 70%+ of references
      - SUPPLEMENTARY: Medium score or entity
      - CONTEXTUAL:    Low-frequency enrichers
    """
    # Normalize tfidf scores to 0-1
    max_tfidf = max(tfidf_terms.values()) if tfidf_terms else 1
    norm_tfidf = {k: v / max_tfidf for k, v in tfidf_terms.items()}

    must_have, supplementary, contextual = [], [], []

    # Classify TF·IDF terms
    for term, score in norm_tfidf.items():
        if score >= 0.65:
            must_have.append(term)
        elif score >= 0.35:
            supplementary.append(term)
        else:
            contextual.append(term)

    # Entities with high spread → upgrade to supplementary
    for term, meta in nlp_terms.items():
        if meta["type"] == "ENTITY" and meta["doc_spread"] >= 0.5:
            if term not in must_have:
                supplementary.append(term)
        elif term not in must_have and term not in supplementary:
            contextual.append(term)

    return {
        "must_have": list(dict.fromkeys(must_have)),
        "supplementary": list(dict.fromkeys(supplementary)),
        "contextual": list(dict.fromkeys(contextual)),
    }


# ════════════════════════════════════════════════════════════════════
# STEP 5 — CONTENT SCORER (Blended)
# ════════════════════════════════════════════════════════════════════

def score_draft(
    draft_text: str,
    classified_terms: Dict[str, List[str]],
    reference_texts: List[str],
    tfidf_terms: Dict[str, float],
    nlp_terms: Dict[str, dict],
) -> Dict:
    """
    Blended content score (0–100):
      S = Semantic coverage    30%
      E = Entity coverage      20%
      I = Intent/section cov.  20%
      O = On-page structure    15%
      Q = Quality/naturalness  15%
      P = Penalty deductions
    """
    draft_clean = clean_text(draft_text)
    draft_tokens = tokenize(draft_text)
    draft_word_count = len(draft_clean.split())
    ref_word_counts = [len(clean_text(r).split()) for r in reference_texts]
    avg_ref_words = sum(ref_word_counts) / len(ref_word_counts) if ref_word_counts else 800

    # ── S: Semantic Term Coverage ────────────────────────────────────
    must_have = classified_terms["must_have"]
    supplementary = classified_terms["supplementary"]

    mh_hits = sum(1 for t in must_have if t in draft_clean)
    sup_hits = sum(1 for t in supplementary if t in draft_clean)
    mh_score = mh_hits / max(len(must_have), 1)
    sup_score = sup_hits / max(len(supplementary), 1)
    S = min(1.0, 0.7 * mh_score + 0.3 * sup_score)

    # ── E: Entity Salience Coverage ──────────────────────────────────
    high_salience_entities = [
        k for k, v in nlp_terms.items()
        if v["type"] == "ENTITY" and v["doc_spread"] >= 0.4
    ]
    entity_hits = sum(1 for e in high_salience_entities if e in draft_clean)
    E = min(1.0, entity_hits / max(len(high_salience_entities), 1))

    # ── I: Intent Coverage (TF·IDF cosine similarity vs references) ──
    if SKLEARN_AVAILABLE and reference_texts:
        vec = TfidfVectorizer(stop_words="english", max_features=300)
        corpus = reference_texts + [draft_text]
        matrix = vec.fit_transform(corpus)
        ref_matrix = matrix[:-1]
        draft_vec = matrix[-1]
        sims = cosine_similarity(draft_vec, ref_matrix).flatten()
        I = float(sims.mean())
    else:
        # Fallback: overlap of top tfidf terms
        top_terms = list(tfidf_terms.keys())[:30]
        hits = sum(1 for t in top_terms if t in draft_clean)
        I = hits / max(len(top_terms), 1)

    # ── O: On-page Structure Score ───────────────────────────────────
    has_h1 = bool(re.search(r"<h1[^>]*>.*?</h1>", draft_text, re.IGNORECASE | re.DOTALL)
                  or re.search(r"^#\\s+.+", draft_text, re.MULTILINE))
    has_h2 = bool(re.search(r"<h2[^>]*>.*?</h2>", draft_text, re.IGNORECASE | re.DOTALL)
                  or re.search(r"^##\\s+.+", draft_text, re.MULTILINE))
    word_ratio = draft_word_count / max(avg_ref_words, 1)
    length_score = 1.0 if 0.7 <= word_ratio <= 1.5 else max(0, 1 - abs(word_ratio - 1.0))
    O = (0.3 * int(has_h1) + 0.3 * int(has_h2) + 0.4 * length_score)

    # ── Q: Quality / Naturalness ─────────────────────────────────────
    # Lexical diversity (unique tokens / total tokens)
    unique_ratio = len(set(draft_tokens)) / max(len(draft_tokens), 1)
    lexical_diversity = min(1.0, unique_ratio * 2)

    # Paragraph usefulness — avg words per paragraph
    paragraphs = [p.strip() for p in re.split(r"\\n{2,}", draft_text) if p.strip()]
    avg_para_len = sum(len(p.split()) for p in paragraphs) / max(len(paragraphs), 1)
    para_score = min(1.0, avg_para_len / 80)  # 80 words per para is healthy

    Q = 0.5 * lexical_diversity + 0.5 * para_score

    # ── P: Penalty ───────────────────────────────────────────────────
    penalties = 0.0

    # Keyword stuffing: any must-have term appearing > 3% of total words
    for term in must_have[:10]:
        count = draft_clean.count(term)
        density = count / max(draft_word_count, 1)
        if density > 0.03:
            penalties += 5  # -5 per stuffed term

    # Over-length bloat
    if word_ratio > 2.5:
        penalties += 10

    # Under-length thin content
    if draft_word_count < 300:
        penalties += 15

    # Too-low lexical diversity (repetitive / spun content)
    if unique_ratio < 0.3:
        penalties += 10

    penalties = min(penalties, 30)  # cap at 30

    # ── Final blended score ──────────────────────────────────────────
    raw = (0.30 * S + 0.20 * E + 0.20 * I + 0.15 * O + 0.15 * Q) * 100
    final_score = max(0, round(raw - penalties, 1))

    return {
        "final_score": final_score,
        "breakdown": {
            "semantic_coverage_S": round(S * 100, 1),
            "entity_coverage_E": round(E * 100, 1),
            "intent_coverage_I": round(I * 100, 1),
            "onpage_structure_O": round(O * 100, 1),
            "quality_naturalness_Q": round(Q * 100, 1),
        },
        "penalties_deducted": penalties,
        "stats": {
            "draft_words": draft_word_count,
            "avg_reference_words": round(avg_ref_words),
            "must_have_covered": f"{mh_hits}/{len(must_have)}",
            "entity_covered": f"{entity_hits}/{len(high_salience_entities)}",
        },
    }


# ════════════════════════════════════════════════════════════════════
# MAIN PIPELINE — Run everything
# ════════════════════════════════════════════════════════════════════

def run_pipeline(
    query: str,
    reference_texts: List[str],
    draft_text: str,
    verbose: bool = True,
) -> Dict:
    """
    Full pipeline:
      1. Extract TF·IDF terms (Surfer-style)
      2. Extract NLP entities + noun chunks (NeuronWriter-style)
      3. Classify into must-have / supplementary / contextual
      4. Score the draft
      5. Return detailed report
    """
    print(f"\\n[Pipeline] Query: \\"{query}\\"")
    print(f"[Pipeline] References: {len(reference_texts)} | Draft words: {len(draft_text.split())}")

    # Step 1
    print("\\n[1/4] Extracting TF·IDF terms (Surfer-style)...")
    tfidf_terms = surfer_style_tfidf_terms(reference_texts, top_n=60)
    print(f"      Found {len(tfidf_terms)} terms. Top 10: {list(tfidf_terms.keys())[:10]}")

    # Step 2
    print("\\n[2/4] Extracting NLP entities + noun chunks (NeuronWriter-style)...")
    if SPACY_AVAILABLE:
        nlp_terms = neuronwriter_style_nlp_terms(reference_texts, top_n=60)
        entities = {k: v for k, v in nlp_terms.items() if v["type"] == "ENTITY"}
        print(f"      Found {len(nlp_terms)} NLP terms ({len(entities)} entities)")
    else:
        print("      spaCy not available — skipping entity extraction")
        nlp_terms = {}

    # Step 3
    print("\\n[3/4] Classifying terms into priority tiers...")
    classified = classify_terms(tfidf_terms, nlp_terms, len(reference_texts))
    print(f"      Must-have: {len(classified[\'must_have\'])} | "
          f"Supplementary: {len(classified[\'supplementary\'])} | "
          f"Contextual: {len(classified[\'contextual\'])}")

    # Step 4
    print("\\n[4/4] Scoring draft...")
    result = score_draft(draft_text, classified, reference_texts, tfidf_terms, nlp_terms)

    if verbose:
        print("\\n" + "="*50)
        print(f"  CONTENT SCORE: {result[\'final_score\']} / 100")
        print("="*50)
        for k, v in result["breakdown"].items():
            bar = "█" * int(v // 5) + "░" * (20 - int(v // 5))
            print(f"  {k:<28} {bar} {v}")
        print(f"  Penalties deducted: -{result[\'penalties_deducted\']}")
        print(f"  Draft words: {result[\'stats\'][\'draft_words\']} "
              f"(avg ref: {result[\'stats\'][\'avg_reference_words\']})")
        print(f"  Must-have covered: {result[\'stats\'][\'must_have_covered\']}")
        print(f"  Entities covered:  {result[\'stats\'][\'entity_covered\']}")
        print("="*50)

    return {
        "query": query,
        "score": result,
        "terms": {
            "tfidf_top30": list(tfidf_terms.keys())[:30],
            "classified": classified,
            "nlp_entities": {
                k: v for k, v in list(nlp_terms.items())[:20]
            } if nlp_terms else {},
        },
    }

def clean_text(text: str) -> str:
    """Lowercase, remove HTML tags, collapse whitespace."""
    text = re.sub(r"<[^>]+>", " ", text)
    text = re.sub(r"\s+", " ", text.lower())
    return text.strip()
